User Guide and Technical Reference

Version 0.2.0 Manual

Reference documentation and workflow guide for version 0.2.0.

1. Overview and What's New in v0.2.0

FXsonic identifies audio tracks, updates tags, and organizes files. It uses Chromaprint (fpcalc) to generate acoustic fingerprints, queries AcoustID and MusicBrainz for release data, writes standard ID3v2.4 tags, and embeds front cover art.

Version 0.2.0 adds multi-folder intake, duplicate detection with album consolidation, column sorting, contextual selection filters, and bulk artwork replacement.

Multi-Folder and Appending Intake New

Select and drag several folders at once. Hold Ctrl while dropping to append tracks to the active list without clearing previous files or creating duplicates.

Contextual Selection Filters New

Filter by artist, album, folder, or status. Clicking any track row selects all matching sibling tracks across the library.

Clickable Header Sorting New

Sort by filename, artist, title, album, year, track number, or status. Click once for ascending order, twice for descending, or three times to reset.

Duplicate Detection and Consolidation New

Find repeated tracks by acoustic fingerprint, metadata, and normalized filename stems. One click consolidates unique tracks into a single album folder without numbered duplicate suffixes.

Bulk Artwork Replacement New

Pick a track with good cover art, then click Replace Art for All Tracks in the inspector to copy that artwork across every staged track.

Clean Track Titles and Batch Editing New

Strip bracketed tags, website URLs, and rip markers from track titles in bulk. Edit album-level tags across selected tracks in one dialog.

2. Intake and Multi-Folder Staging

Add audio tracks by dragging files or folders onto the drop zone, or click Browse in the top navigation bar. The scanner reads all subdirectories automatically.

Ctrl + Drop to Append Tracks

Dropping files normally replaces the current staging list with the new files. Holding Ctrl while dropping appends new files to the active session and skips tracks that are already loaded.

3. Top Navigation Bar and Processing Actions

The top bar manages source folder selection, matching, and tag writing:

  • Directory path field: Shows the active source folder. Click Browse to choose a folder using the system file picker.
  • Process Album: Computes acoustic fingerprints with fpcalc, then queries AcoustID and MusicBrainz for release data.
  • Apply Changes: Writes resolved ID3v2.4 tags, embeds cover art, and renames or moves files if those options are checked.
  • Cancel / Abort: Stops a running scan or write job, or clears the staging table when idle.
  • Theme toggle: Click the brand logo to switch between dark and light modes.

4. Options Bar and Formatting Controls

The bar directly below the top navigation controls metadata cleanup and output paths:

Fetch Cover Art

Downloads front cover images from the Cover Art Archive (500px to 1200px) and embeds them into track tags as JPEGs.

Strip Junk Info

Removes advertising comments, promotional URLs, encoder strings, and rip tags from track containers.

Prefer Romanized Script

Converts non-Latin scripts (such as Kanji, Cyrillic, or Hanzi) to Latin aliases when provided by MusicBrainz.

Organize Files

Sorts output files into a clean folder hierarchy: Artist / [Year] - Album / [Disc-]Track - Title.ext.

Rename Files to Song Title

Sets the output filename to the clean song title and removes illegal characters like colons, quotes, and slashes.

Output Destination and Reset

Click Change to export tagged files to a separate directory. Click Reset (In-Place) to write changes directly to original files.

5. Contextual "Select By" and Staging Filters

The filter bar makes it easy to work with large libraries and multi-artist collections:

When a mode in the Select By menu is active, clicking any track row automatically isolates and selects all sibling tracks matching that criterion:

  • Select By: Artist: Click any track to select all tracks by that artist.
  • Select By: Album: Click any track to select its full album.
  • Select By: Folder: Click any track to select all tracks from the same directory.
  • Select By: Status: Click any track to select all tracks sharing that verification state.
  • Show All: Clears the active filter and restores the full list.
  • Status dropdown: Limits the view to all tracks, identified tracks, ambiguous matches, or unmatched files.
  • Filter tracks input: Filters visible rows as you type by filename, title, artist, or album.

7. Staging Workbench Rows and Waveforms

Each row in the staging table represents an individual audio file:

  • Checkbox: Toggles inclusion in tag writing and file renaming. The header checkbox toggles all visible tracks.
  • Status badges:
    • STAGED: Track loaded locally, awaiting identification or tag write.
    • VERIFIED: Confirmed match from MusicBrainz.
    • AMBIGUOUS: Multiple potential release matches found. Review proposed tags in the Inspector.
    • UNMATCHED: No database match found. Original local tags are kept.
  • Acoustic Waveform Icon (graphic_eq): The soundwave icon indicates that an acoustic fingerprint was calculated for this file.

8. Inspector Panel and Universal Artwork Injection

The right-hand panel displays artwork previews, diagnostics, and proposed tag differences for the selected track:

Cover Art Viewer

Shows embedded or downloaded cover art with pixel dimensions (such as 1000 × 1000), format (JPEG), and file weight (66 KB).

PLAY TRACK Audio Player

Click Play Track to preview the audio file before writing changes or unstaging files.

REPLACE ART FOR ALL TRACKS New

Select any track with good artwork, then click Replace Art (N) to inject that image across all staged tracks in the library.

METADATA DIFF and EDIT TRACK DATA

Review original tags alongside proposed MusicBrainz tags, or switch to Edit Track Data to modify fields manually.

9. Duplicate Detection and Smart Album Consolidation

Music collections frequently accumulate duplicate songs across singles, compilations, and reissues. Clicking Select Duplicates on the toolbar runs three checks:

  1. Acoustic Fingerprint Hash: Matches identical audio waveforms even when track titles or filenames differ.
  2. Metadata Matching: Matches normalized title, artist, and duration within a three-second window.
  3. Filename Stem Normalization: Strips track numbers, disc prefixes, bitrates, and extensions to find identical tracks stored in different folders.

Duplicate Action Dialog Options

  • Consolidate to Unique Album: Evaluates track quality across duplicates, preferring lossless formats (FLAC or WAV) over lossy formats (MP3 or M4A), and higher bitrates. It unstages redundant copies and combines all unique tracks into a single destination folder without version suffixes like (1) or (2).
  • Unstage Duplicates Only: Keeps the highest quality version of each song and removes duplicate rows from the active table, leaving original files on disk untouched.

10. Clean Track Titles and Batch Metadata Editing

Audio tracks downloaded from web sources often carry website URLs, bracketed rip tags, and promotional strings in their title fields:

CLEAN TRACK TITLES Dialog New

Click Clean Track Titles on the toolbar. Enter any search string (such as [Official Video], [320kbps], or a website name) and click Clean to remove that phrase from all selected titles.

EDIT ALBUM METADATA Dialog

Updates album title, album artist, release year, genre, and total disc count across all tracks in an album simultaneously.

11. Multi-Disc Box Set Heuristics and Local Cache

FXsonic v0.2.0 includes multi-disc track numbering parsers and local SQLite caching:

Multi-Disc Numbering Heuristics

Parses 3-digit and 4-digit disc prefixes (such as 101 for Disc 1, Track 01, and 204 for Disc 2, Track 04), hyphenated numbers (1-01, 2-12), and continuous numbering across multi-disc releases (where tracks 13+ on a 2-CD release map to Disc 2).

Persistent SQLite Cache (cache.db)

Acoustic fingerprints are saved in cache.db, indexed by file path, size, and modification date. Rescanning an existing folder skips fpcalc execution and loads almost instantly.

Status Footer and Theme Controls

The bottom status bar shows background task progress and theme settings:

  • Theme toggle: Located on the bottom left. Click the moon or sun icon to switch themes.
  • Progress bar: Shows scan percentage and processed track counts in real time.
  • Telemetry counters: Green, orange, and gray counters track identified, ambiguous, and unmatched counts.
  • Status console: Displays the latest system event and loaded track count.
